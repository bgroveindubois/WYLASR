\## WYLAS Bifilar PCB Designer



The WYLAS Bifilar PCB Designer is a Python/Tkinter application used to generate

planar bifilar coil geometry, WYLASR coil arrays, DXF files, and Autodesk

Fusion Electronics PCB automation scripts.



\## Requirements



\- Python 3.10 or newer recommended

\- Tkinter

\- No third-party Python packages are currently required



The program uses only Python standard-library modules:



\- tkinter

\- math



Therefore:



&#x20;   pip install



is \*\*not required\*\*.



\## Windows Installation



\### 1. Install Python



Download and install Python 3 from:



https://www.python.org/downloads/



During installation, enable:



&#x20;   Add Python to PATH



A normal Python installation for Windows includes Tkinter.



\### 2. Verify Python



Open Command Prompt or PowerShell and run:



&#x20;   python --version



You should see something similar to:



&#x20;   Python 3.13.x



\### 3. Verify Tkinter



Run:



&#x20;   python -m tkinter



A small Tkinter demonstration window should open.



If the window opens, Tkinter is installed correctly.



\### 4. Run WYLAS Bifilar PCB Designer



From the repository directory:



&#x20;   cd software



Then run:



&#x20;   python "WYLAS Bifilar PCB Designer.py"



Alternatively, on Windows the `.py` file may be opened directly if Python

file associations are configured.



\## pip Requirements



There are currently no external pip dependencies.



You do NOT need to run:



&#x20;   pip install tkinter



Tkinter is supplied with the standard Windows Python installation and is not

normally installed through pip.



A `requirements.txt` file is therefore not currently necessary.



\## Generated Files



The PCB Designer can generate:



\- DXF coil geometry

\- Autodesk Fusion Electronics `.scr` automation scripts

\- Single-cell PCB layouts

\- Multi-cell WYLASR array layouts





The generated Fusion Electronics scripts create PCB geometry including:



\- Planar bifilar coils

\- Copper routing

\- Plated through vias

\- Non-plated core/nail holes

\- Soldermask / coverlay openings

\- PCB outline

\- Array interconnections



\## Autodesk Fusion



Generated `.scr` files are intended to be run from the Autodesk Fusion

Electronics PCB editor.



In Fusion Electronics use:



&#x20;   Automation > Run Script



Select the `.scr` file generated by the WYLAS Bifilar PCB Designer.



Always inspect the resulting PCB and manufacturing outputs before fabrication.



\## Development



The software is intentionally kept lightweight so the PCB geometry generator

can run on a standard Python installation without requiring a Python package

environment.



If third-party dependencies are introduced in the future, they will be listed

in `requirements.txt`.
